Notes

This page is the offline demo that ships with WebTape. It needs no server and makes no network requests, so it opens straight from disk.

Edit demo.tape to change what gets recorded, then run it again. The same script gives the same number of frames every time.

  • Press Enter in the text box to put a new task on the list.
  • Click a circle to mark a task as done.
  • The list scrolls on its own; so does the page.
  • Swap this page for your own app with a single Goto line.
